# Content Unhider v1.0.0

Initial GitHub release of the Manifest V3 Chrome extension.

## Included

- On-demand webpage style adjustments using editable CSS selectors.
- Hide matching overlays, restore CSS-hidden paragraphs, clear blur filters, and unlock scrolling.
- Optional observation of dynamically inserted page elements.
- Per-website saved configuration using Chrome local storage.
- Restore changes without refreshing the page.
- Minimal permissions: `activeTab`, `scripting`, and `storage`.

## Install

1. Download **content-unhider-v1.0.0.zip** from the Assets section below.
2. Extract the ZIP into a permanent folder.
3. Open `chrome://extensions/` in Chrome and enable **Developer mode**.
4. Select **Load unpacked** and choose the extracted folder containing `manifest.json`.
5. Open a normal webpage, click Content Unhider, and choose **Apply to this tab**.

Do not try to load the ZIP itself with **Load unpacked**. Extract it first.

## Validation

- JavaScript syntax checks and dependency-free controller unit tests passed.
- Chromium DOM smoke tests passed for style modification, restoration, dynamic page elements, and the popup controls, with extension APIs mocked.
- Full extension installation and the actual `activeTab` toolbar permission path could not be tested in the restricted automated Chromium environment. Manual Chrome verification is recommended.

## Limitations

The extension can only change content already present in the browser. It cannot obtain material withheld by a server or grant access you are not authorized to have. Website-specific selectors may be needed. It runs only when you click Apply.
